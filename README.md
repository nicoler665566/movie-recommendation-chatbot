# Mr. Bot | Movie Recommendation Chatbot

Explore content-based movie recommendations from movie metadata.

## Technical approach

Preprocess text with NLTK, construct TF-IDF features, compare movies using cosine similarity, and explore clustering with KMeans and PCA.

## Technologies

Python, pandas, scikit-learn, NLTK, matplotlib, seaborn

## Project materials

- `MR. Bot.pptx`
- `NLP RIEPL FINAL.pdf`
- `MR BOT.ipynb`

## Getting started

Open MR BOT.ipynb; the notebook downloads NLTK resources and reads an external movie CSV. This is an NLP recommender, not evidence of a production LLM agent.

For notebooks, use a compatible Python/Jupyter environment and install the imported libraries. Original environment-specific paths may need local adjustment.
